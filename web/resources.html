Docker file for n8n, Ollama, Qdrant and NEO4J.

Docker file for n8n only

version: '3.8'

services:
  n8n:
    image: n8nio/n8n:latest
    container_name: n8n
    restart: unless-stopped
    ports:
      - "5678:5678"
    volumes:
      - n8n_data:/home/node/.n8n

volumes:
  n8n_data:

To use this Docker Compose file:

  1. Save the content: Copy the YAML content above and save it into a file named docker-compose.yml in a directory of your choice.

  2. Open your terminal: Navigate to the directory where you saved docker-compose.yml.

  3. Run Docker Compose: Execute the command:

    docker compose up -d

  4. Access n8n: Once the container is running (it might take a moment to pull the image the first time), open your web browser and go to http://localhost:5678.
