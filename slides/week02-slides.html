LLM vs. AI Agent

Feature LLM (The Brain) AI Agent (The Worker)
Core Capability Text generation & knowledge Goal-oriented task completion
Decision-Making None (predicts next word) Yes (chooses what to do next)
Tool Use No (Static) Yes (Uses APIs, Web, n8n)
Workflow Single-step (Prompt -> Result) Multi-step (Loop until finished)
Scope Generates language Performs real-world actions
Example Writing a poem Researching a lead and sending an email

The “Recipe” Analogy

A Workflow must be:

  • Explicit: No guessing. Every step is defined.

  • Repeatable: If you follow the recipe exactly, you get the same meal every time.

  • Automatable: Once the recipe is clear, a “robot chef” (n8n) can do the cooking for you.

  • Programming: Think of it as traditional programming (vs. generative AI)

Deterministic vs. Agentic

Deterministic

The Traditional Way

  • Rules-based: “If This, Then That.”
  • Fixed Paths: Every step is pre-defined.
  • Predictable: Given the same input, you always get the same output.
  • Analogy: A train on tracks.

Agentic

The AI-Powered Way

  • Goal-based: “Find the answer to X.”
  • Dynamic Paths: The AI decides which tools to use in real-time.
  • Flexible: Can handle unexpected data or “fuzzy” logic.
  • Analogy: A taxi driver.

n8n

n8n - background

n8n is an open-source, node-based workflow automation tool that enables users to connect various apps and services to automate tasks without extensive coding (No-code/low-code)

  • Automates complex workflows by connecting APIs, databases, and cloud services.
  • Offers a visual, drag-and-drop interface to build workflows.
  • Supports custom code with JavaScript (and Python) for advanced logic.
  • Integrates with hundreds of applications out-of-the-box.
  • Useful for automating repetitive tasks, data synchronization, alerts, and more.

Self-hosted vs. cloud

  • n8n is available as both self-hosted and cloud versions.
  • We are using the self-hosted version.
    • Cost: “Free” (Community edition).
  • Updates are released weekly – you are not expected to update every week.
  • LLMs (Large Language Models) are accessed via:
    • Ollama (Local/Private).
    • APIs for ChatGPT, Gemini, etc. (May incur usage costs).

Starting with n8n

The n8n Interface

The n8n dashboard is designed to be intuitive and visual.

  • Workflow Canvas: The main area where you build. It is an infinite digital whiteboard for your logic.
  • Nodes Panel: Located on the right (opened via the “+” button). This is your library of 400+ integrations and core tools.
  • Sidebar: Your command center for navigating between your workflow list, credentials, and execution history.
  • Settings: Accessible via the gear icon in the sidebar for environment variables and owner settings.

Core Pillars: Workflows & Nodes

To master n8n, you must understand these three core concepts:

  1. Workflows: A sequence of nodes connected together. A workflow always starts with a Trigger (e.g., a schedule, a webhook, or a manual “chat” prompt).
  2. Nodes: The building blocks. Each node performs one specific action (e.g., “Send an Email,” “Ask ChatGPT,” or “Update Google Sheet”).
  3. Parameters: The configuration inside a node (e.g., which email address to send to).

JSON vs. Binary Data

I n8n arbejder vi primært med to datatyper:

  • JSON (Struktureret data):
    • Tekst, tal, lister og objekter.
    • Det du ser i tabeller og “Schema”-visning.
    • Bruges til logik, filtre og API-kald.
  • Binary (Filer):
    • Billeder, PDF’er, Excel-filer, lyd.
    • Kan ikke læses direkte som tekst af n8n’s standard-logik.
    • Kræver specifikke nodes (f.eks. “Extract from File”) for at blive transformeret til JSON.

Credentials & Executions

Credentials

  • This is where you securely store API keys and logins (e.g., OpenAI API Key).
  • Security: Credentials are encrypted and are separate from the workflow itself, allowing you to share workflows without sharing your keys.

Executions

  • The “Log Book” of your automation.
  • Shows exactly what data passed through every node.
  • Essential for debugging: if a workflow fails, you can see exactly where and why.

Navigation Tips for Beginners

  • Right-Click & Drag: Move around the canvas quickly.
  • Mouse Wheel: Zoom in and out.
  • CMD/CTRL + C / V: You can copy-paste nodes. Interestingly, you can paste n8n nodes as JSON text into Slack/Teams/Email, and others can paste them back into their canvas!
  • Search (/): Use the search bar in the Nodes panel to find integrations quickly.
  • Execute Workflow: Use the big orange button at the bottom to test your logic in real-time.

Node Types & Categories

⚡ The Trigger (How it starts)

Triggers: Every workflow starts here.

  • Schedule (every hour)
  • Webhook (sent from another app)
  • App Event (e.g., “New Row in Google Sheets”).

Node Types & Categories

🛠️ The Building Blocks

  • Action in an app: The “Hands.” Connect to 400+ apps like Slack, Google Sheets, or Notion to send or retrieve data.
  • Data Transformation: The “Filter.” Change data formats, rename fields, or filter out specific information.
  • Flow: The “Logic.” Create branches (If/Else), merge data streams, or loop through lists of items.
  • Core: The “Power Tools.” Write custom JavaScript/Python, make raw HTTP requests, or use Webhooks.

Node Types & Categories

🛠️ The Building Blocks

  • AI: The “Brain.” Build autonomous agents, use chains, or search through your documents using vector stores.
  • Human in the Loop: The “Pause Button.” Stop the workflow and wait for a human to click “Approve” or enter data before continuing.

Ollama

Installer Ollama

  • Installation:
    • Hent og installer fra ollama.com.
    • Kører som en baggrundstjeneste (tjek dit “system tray” ikon).
  • Download din første model:
    • Åbn din terminal (CMD eller PowerShell).
    • Kør: ollama run llama3.2
    • For mindre maskiner: ollama run phi3 eller ollama run tinydolphin.
  • Test i terminalen:
    • Chat direkte i terminalen for at bekræfte, at det virker.
    • Skriv /bye for at afslutte.

Forbind n8n til Ollama

Når du konfigurerer din Ollama Chat Model credential i n8n:

  • Base URL (Hvis n8n kører som Desktop App):
    • http://localhost:11434
  • Base URL (Hvis n8n kører i Docker):
    • http://host.docker.internal:11434
  • Model Name:
    • Skriv det præcise navn (f.eks. llama3.2), eller vælg fra listen hvis forbindelsen er aktiv.

✅ Test forbindelsen

  1. Browser tjek:
    • Gå til http://localhost:11434 i din browser.
    • Du skal se teksten: “Ollama is running”.
  2. n8n tjek:
    • Opret en “AI Agent” node.
    • Tilføj “Chat Model” -> “Ollama Chat Model”.
    • Klik på rullemenuen under “Model”. Hvis dine downloadede modeller dukker op, virker det!
